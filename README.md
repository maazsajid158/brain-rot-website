# Brain‑Rot Tracker

A fun little web app that lets you manually track unproductive time and gets roasted by a random cartoon character.

## Features
- **Manual start/stop timer** – you decide when you’re being unproductive.
- **In‑memory only** – no data is persisted on your device.
- **Random avatar** – a cartoon brain‑rot character appears each session.
- **Dynamic roasts** – the longer you stay idle, the sharper the roast.
- Built with **React + Vite** – fast hot‑reload development experience.

## Getting Started
1. Open a terminal and `cd` into the project folder:
   ```
   cd C:/Users/arsha/.gemini/antigravity/scratch/brain-rot-website/client
   ```
2. Install dependencies (already done automatically, but you can run again if needed):
   ```
   npm install
   ```
3. Start the development server:
   ```
   npm run dev
   ```
4. Open the URL shown in the console (usually `http://localhost:5173`).

## Usage
- Click **Start** when you begin a distraction.
- Click **Stop** when you get back on track.
- Click **Reset** to clear the timer.
- The app will display a roast that gets progressively harsher the longer you stay in “brain‑rot” mode.

## Moving the project
The project lives in the default workspace as required by the system. You can copy the whole `brain-rot-website` folder to any other location (e.g., `D:`) after you are done developing.
